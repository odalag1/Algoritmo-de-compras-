Algoritmo de Controle de Compras com Cartão - Java

Descrição

Desafio proposto pelo fim do curso da Alura com objetivo de criar um simulador de sistema de controle de compras com limite de cartão. O usuário pode definir um limite para o cartão e adicionar compras até que o limite seja atingido. O algoritmo permite registrar compras e verificar se o saldo do cartão é suficiente, exibindo uma lista de produtos comprados quando o limite é atingido ou o usuário decide encerrar as compras.

funcionalidades

O programa realiza as seguintes funções:
Permite definir o limite do cartão.
Adiciona compras informando o nome do produto e o valor.
Valida entradas do usuário para evitar erros ou valores inválidos.
Verifica se o saldo do cartão é suficiente para cada compra.
Exibe uma lista de produtos comprados quando o saldo é insuficiente ou quando o usuário decide parar de realizar compras.

Organiza os produtos comprados em ordem alfabética para melhor visualização

Interação com o Programa:

Insira o limite do cartão.
Adicione compras inserindo o nome do produto e o valor da compra.
O programa verificará se o saldo é suficiente e atualizará o saldo após cada compra.
O programa exibirá uma lista de produtos comprados quando o saldo for insuficiente ou quando o usuário decidir parar de fazer compras.
